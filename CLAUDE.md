# Концепт формы события VK WorkSpace

Кликабельный прототип новой формы события Календаря для внутреннего хакатона. React 19 + Vite, собирается в один HTML-файл (`vite-plugin-singlefile`) и публикуется как артефакт.

Контекст решений, принципы, ссылки на отчёт и карта кода — в документе `CONTEXT.md` проекта «Календарь» в claude.ai (в репозиторий не кладём: там внутренние материалы хакатона). Читай его, только если задача про логику концепта; для правок вёрстки и текстов хватит этого файла.

## Что не коммитим
Репозиторий публичный. Не добавляй в него скриншоты интерфейса VK WorkSpace, бриф, отчёт и другие внутренние материалы — только код прототипа с выдуманными данными.

## Карта кода
Основа Календаря (pixel perfect к макету Figma «Неделя», открывается по умолчанию; прежний концепт — по `#concept`):
- `src/calendar/weekData.ts` — события недели, статусы (подтверждено / пунктир / «возможно»), «сейчас» — вт, 7 апреля, 11:30.
- `src/calendar/WeekGrid.tsx` — сетка недели, события, перенос и растягивание с шагом 15 минут.
- `src/calendar/Chrome.tsx` — навбар сервисов, левая панель, шапка сетки.
- `src/calendar/Calendar.tsx` — сборка экрана; точки входа для вариантов создания: `onSlotClick`, `onCreate`, `overlay`.
- `src/calendar/calendar.css` — размеры из макета на токенах темы calendar.

Концепт формы события:
- `src/data.ts` — данные и логика: подбор слотов, статусы, правило роста формы.
- `src/EventForm.tsx` — форма (поповер и сайдбар), блоки, карточка участника.
- `src/Week.tsx` — недельная сетка, слой занятости, тепловая карта, вид «По людям».
- `src/App.tsx` — пульт сценариев, раскладка календаря, поповер, снекбары.
- `src/styles.css` — раскладка на токенах VKUI.

## Экономия токенов
- Одна задача — один короткий заход; правь только названные файлы.
- Не делай скриншот-проверок и сборку без просьбы: пользователь смотрит результат сам в `npm run dev`.
- Варианты UI добавляй переключателем в пульт (`App.tsx`), а не отдельной копией экрана.

## Компоненты: только VKUI и VK Icons

- **Интерфейс собираем из [VKUI](https://vkui.io/overview/install) (`@vkontakte/vkui`).** Перед тем как писать свой компонент, проверь, нет ли готового в VKUI: Button, IconButton, SegmentedControl, ChipsSelect / ChipsInput, Chip, Avatar, Input, Checkbox, Radio, CustomSelect, Accordion, SimpleCell, Card, Snackbar, Tappable, Title / Text / Footnote / Caption и т. д. Свой компонент допустим только там, где в VKUI аналога нет (сейчас это недельная сетка, тепловая карта занятости, таймлайн «По людям», чипы слотов времени), и он строится на `Tappable` и токенах VKUI.
- **Иконки — только из [@vkontakte/icons](https://vkcom.github.io/icons)** (`Icon20ClockOutline`, `Icon16Add`…). Не рисуем SVG вручную и не берём иконки из других наборов. Размер иконки соответствует контексту: 20 — в строках формы, 16 — в маленьких кнопках и чипах.
- **Цвета, радиусы и шрифты берём из токенов VKUI** (`var(--vkui--color_text_secondary)`, `var(--vkui--size_border_radius--regular)` и т. п.), а не хардкодим. Своих hex-цветов — только для данных, которых нет в теме (цвета календарей руководителей, тепловая карта).
- **Тема — `calendar` из `@vkontakte/vkui-tokens`** (стилистика Календаря Mail / Paradigm): подключена в `src/main.tsx` через `tokensClassNames` у `ConfigProvider`. Не переключаем на vkBase.

## Настройка по официальному гайду VKUI

- Корень: `ConfigProvider` → `AppRoot` → `App`, импорт `@vkontakte/vkui/dist/vkui.css` в `src/main.tsx`.
- В `index.html` — meta viewport с `viewport-fit=cover`.
- После установки или обновления `@vkontakte/icons` запускать `npm dedupe`.

## Команды

- `npm run dev` — локальный сервер.
- `npm run build` — сборка в `dist/index.html` (один файл, всё заинлайнено; для артефакта внешние скрипты запрещены).

## Ограничения хакатона

- Не уходим от стилистики продуктов Mail и дизайн-системы Paradigm.
- Данные в прототипе выдуманные (`src/data.ts`), «сейчас» — среда, 15 апреля, 13:20.
