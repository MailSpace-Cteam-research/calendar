# Концепт формы события

Кликабельный прототип формы события календаря на [VKUI](https://vkui.io) и [VK Icons](https://vkcom.github.io/icons), тема `calendar` из `@vkontakte/vkui-tokens`. Данные выдуманные.

```bash
npm install
npm run dev     # локальный сервер
npm run build   # один HTML-файл в dist/index.html
```

Правила работы с проектом — в `CLAUDE.md`.
